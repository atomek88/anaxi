# The questions

**Why.** Depth is answered questions, so the questions are the measuring stick. Without a shared set, "D2" means
whatever the writer thinks it means, and two reviewers disagree on the same doc.

**What.** Principles, each level's aim, bounds and "done when", ten core questions, project questions in
`anaxi-questions.md` (each with an optional `when:` matched against an item's `about:`), and each item's own
checklist, where an unchecked box is an open question. The set is alive: questions are proposed, challenged and
retired with a reason. Out of scope: applying library questions automatically.

**Shape.** Three layers, core → project → item, each able to change the one above it with a reason. The scripts
list which questions apply; whether one is answered is judged by a person or the skill (@skill), never by keyword
matching, which is easy to game. The question library is wording to borrow, not a rule set.
